<h2 align="center">🐍 Contribution Snake</h2>

<!--
SETUP REQUIRED:

The contribution snake will appear only after the GitHub Action
has successfully generated the SVG files.

1. Open your GitHub profile repository:
   Praveenraj-N/Praveenraj-N

2. Create the following file:
   .github/workflows/snake.yml

3. Copy the YAML configuration below into that file.

4. Commit and push the workflow.

5. Open the Actions tab and run "Generate Contribution Snake".

6. The workflow creates an output branch containing the SVG files.

7. If publishing fails, check the repository's Actions permissions
   and confirm that the workflow is allowed to write repository contents.

==================== SNAKE WORKFLOW ====================

name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

concurrency:
  group: contribution-snake
  cancel-in-progress: true

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Generate Snake Animations
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg?color_snake=#FF69B4&color_dots=#FCE4EC,#F8BBD0,#EF93C4,#FF69B4,#C2185B
            dist/github-snake-dark.svg?palette=github-dark&color_snake=#FF69B4&color_dots=#161B22,#4A253D,#9E4778,#EF93C4,#FF69B4

      - name: Publish Snake Animations
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

================== END SNAKE WORKFLOW ==================

If your default branch is master instead of main,
update the workflow's push branch accordingly.
